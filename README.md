# Учет выданного аванса

Яркое мобильное PWA-приложение для учета авансов, выданных сотрудникам (комбайнерам).

**Живой сайт:** https://maaloznal.github.io/murad-app/

## Возможности

- Дашборд: общая выданная сумма, число сотрудников и выдач, средний аванс, график за 14 дней
- Карточки «Больше всех» и «Меньше всех» — сразу видно лидеров
- Итоговая сумма видна рядом с именем каждого сотрудника, без открытия таблицы
- Сортировка: по сумме (больше/меньше всех), по имени, по количеству выдач
- Периоды: все время / месяц / 7 дней / сегодня, поиск по имени и гос. номеру
- Добавление: имя, фамилия, гос. номер комбайна, дата (по умолчанию сегодня), сумма
- Журнал выдач по дням с удалением записей и экспортом в CSV
- Установка как приложение (PWA) на Android, iOS и ПК, офлайн-режим, темная тема

## Как это устроено

- Фронтенд — статические файлы без сборки, размещены на GitHub Pages
- Данные — Google-таблица через Google Apps Script Web App (`doGet` / `doPost`, действия `add` и `delete`)
- Все запросы подписываются секретным ключом `API_KEY`; ключ лежит в двух местах и должен совпадать:
  - `app.js` → `API_KEY`
  - `backend/Code.gs` → `CONFIG.API_KEY`

## Защита данных

Раньше ссылка на Apps Script была полностью открытой: любой, кто заглядывал в код приложения,
мог читать, менять и удалять данные, а сама таблица была доступна по ссылке. Теперь:

1. **Ключ доступа.** `doGet`/`doPost` принимают запросы только с правильным ключом, чужие — отклоняются (`code: "AUTH"`).
2. **Проверка данных.** Лимиты длины полей, диапазон суммы (1–10 млн), формат даты, формат ID — мусор не запишется.
3. **Лимит запросов.** 600 чтений и 120 записей в час на всех — защита от ботов и заливки.
4. **Журнал действий** (лист «Журнал»). Каждая выдача и удаление фиксируются с датой и временем — удалённое можно восстановить.
5. **Резервные копии** (листы «Резерв …»). Ежедневная копия листа «Выдачи» в 3:00, хранятся последние 14.
6. **Доступ к таблице — «Ограниченный»** (только владелец). Скрипт выполняется от имени владельца и продолжает работать.
7. **Защита листов.** Листы «Выдачи», «Сводка», «Журнал» и резервов закрыты от редактирования всеми, кроме владельца.

Честное ограничение: фронтенд публичный, поэтому ключ виден тому, кто целенаправленно изучит
код приложения. Ключ отсекает ботов, сканеры и случайных людей, но для полной приватности нужен
сервер с авторизацией пользователей — при необходимости можно добавить.

## Настройка (один раз, ~5 минут)

1. Откройте таблицу → **Расширения → Apps Script**, удалите весь старый код и вставьте
   содержимое [`backend/Code.gs`](backend/Code.gs) → **Сохранить**.
2. Сверьте `CONFIG.API_KEY` с `API_KEY` в `app.js` — они должны совпадать.
3. В редакторе Apps Script выберите функцию **`installDailyBackup`** → **Выполнить** (один раз):
   создаст триггер ежедневного бэкапа, сделает первую копию и защитит листы.
4. **Развернуть → Управление развертываниями → карандаш → «Версия: Новая версия» → Развернуть.**
   Ссылка на веб-приложение не изменится.
5. В таблице: **Файл → Настроить доступ → Общий доступ: «Ограниченный»**
   (убрать «Все, у кого есть ссылка»). Если таблица публиковалась в интернет
   (**Файл → Опубликовать в интернете**) — остановите публикацию.
6. Проверка: откройте ссылку `.../exec` в браузере без параметров — должно прийти
   `{"status":"error","code":"AUTH",...}`. Значит, защита работает.

В Apps Script должно остаться **«Кто имеет доступ: Все»** — это доступ к *скрипту* (он сам защищён
ключом), а не к таблице.

## Структура

| Файл | Назначение |
|---|---|
| `index.html`, `styles.css`, `app.js` | Приложение |
| `manifest.webmanifest`, `service-worker.js`, `icons/` | PWA: установка и офлайн-кэш |
| `backend/Code.gs` | Код Google Apps Script для таблицы |

После изменений в оболочке приложения поднимайте версию кэша в `service-worker.js`
(`CACHE = "avans-v2"` → `avans-v3`), чтобы у пользователей обновилось.
