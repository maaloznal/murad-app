# Учет выданного аванса

Яркое мобильное PWA-приложение для учета авансов, выданных сотрудникам (комбайнерам).

**Живой сайт:** https://maaloznal.github.io/murad-app/

## Возможности

- Дашборд: общая выданная сумма, число сотрудников и выдач, средний аванс, график за 14 дней
- Карточки «Больше всех» и «Меньше всех» — сразу видно лидеров
- Итоговая сумма видна рядом с именем каждого сотрудника, без открытия таблицы
- Сортировка: по сумме (больше/меньше всех), по имени, по количеству выдач
- Периоды: все время / месяц / 7 дней / сегодня, поиск по имени и гос. номеру
- Добавление: имя, фамилия, гос. номер комбайна, дата (по умолчанию сегодня), сумма
- Журнал выдач по дням с удалением записей и экспортом в CSV
- Установка как приложение (PWA) на Android, iOS и ПК, офлайн-режим, темная тема

## Как это устроено

- Фронтенд — статические файлы без сборки, размещены на GitHub Pages
- Данные — Google-таблица через Google Apps Script Web App (`doGet` / `doPost`, действия `add` и `delete`)
- Вход по личным кодам: код проверяет сервер в `CONFIG.USERS` (редактор Apps Script
  вашей Google-таблицы), в публичном коде приложения секретов нет

## Защита данных и авторизация

Раньше ссылка на Apps Script была полностью открытой: любой, кто заглядывал в код приложения,
мог читать, менять и удалять данные, а сама таблица была доступна по ссылке. Теперь:

1. **Вход по личным кодам.** Пользователь вводит код доступа — сервер (Apps Script) проверяет
   его в `CONFIG.USERS` и без правильного кода не отдаёт данные. Коды живут только на сервере,
   в публичном коде приложения секретов нет. Сторонние сервисы не используются.
2. **Пользователи и коды** задаются в Apps Script таблицы → `CONFIG.USERS`.
   Добавить сотрудника — новая строка + новая версия развертывания; отозвать доступ —
   удалить строку или сменить код.
3. **Защита от подбора.** После 5 неверных попыток за час каждая следующая замедляется на 3 сек;
   плюс общий лимит запросов (600 чтений / 120 записей в час).
4. **Проверка данных.** Лимиты длины полей, диапазон суммы (1–10 млн), формат даты, формат ID.
5. **Журнал действий** (лист «Журнал»). Каждая выдача и удаление фиксируются с именем пользователя
   и временем — удалённое можно восстановить.
6. **Резервные копии** (листы «Резерв …»). Ежедневная копия листа «Выдачи» в 3:00, хранятся последние 14.
7. **Доступ к таблице — «Ограниченный»** (только владелец). Скрипт выполняется от имени владельца
   и продолжает работать.
8. **Защита листов.** Листы «Выдачи», «Сводка», «Журнал» и резервов закрыты от редактирования
   всеми, кроме владельца.

Код хранится на устройстве в localStorage после входа. Кнопка «Выйти» (в шапке) удаляет и код,
и локальную копию данных с устройства.

Честное ограничение: это вход по общему секрету, а не полноценные аккаунты с регистрацией.
Для полной приватности каждому — свои коды в `CONFIG.USERS` и отзыв доступа при увольнении.

> **Важно:** серверный код удалён из репозитория, чтобы коды доступа не были видны
> публично. Но старые версии файла остались в истории коммитов (она публична навсегда).
> Если при установке вы не сменили пример кода `avans-3af0963d` — смените его сейчас
> в `CONFIG.USERS` и разверните новую версию.

## Код сервера (Apps Script)

Серверный код **не хранится в репозитории** — он живёт в Apps Script вашей Google-таблицы
(**Расширения → Apps Script**). Последняя копия для восстановления — в истории коммитов
(коммит `1b8fc66` «Авторизация: вход в приложение по личным кодам доступа»).

Если понадобится развернуть с нуля (новая таблица):
1. **Расширения → Apps Script**: удалить старый код, вставить код из истории репозитория → **Сохранить**.
2. В `CONFIG.USERS` задать своё имя и код (коды придумать свои; сотрудникам — по строке на человека).
3. Один раз выполнить функцию **`installDailyBackup`** (список функций → Выполнить):
   создаст триггер ежедневного бэкапа, сделает первую копию и защитит листы.
4. **Развернуть → Управление развертываниями → карандаш → «Версия: Новая версия» → Развернуть**
   (ссылка на веб-приложение не изменится).
5. В таблице: **Файл → Настроить доступ → «Ограниченный»** (убрать «Все, у кого есть ссылка»);
   если таблица публиковалась в интернет (**Файл → Опубликовать в интернете**) — остановить публикацию.

Доступ к *скрипту* в Apps Script остаётся **«Кто имеет доступ: Все»** — скрипт сам требует
код доступа, это не доступ к таблице.

Проверка защиты: открыть ссылку `.../exec` в браузере без параметров — должно прийти
`{"status":"error","code":"AUTH",...}`.

## Структура

| Файл | Назначение |
|---|---|
| `index.html`, `styles.css`, `app.js` | Приложение |
| `manifest.webmanifest`, `service-worker.js`, `icons/` | PWA: установка и офлайн-кэш |

Код Google Apps Script хранится в редакторе Apps Script вашей таблицы — в репозитории его нет.

После изменений в оболочке приложения поднимайте версию кэша в `service-worker.js`
(`CACHE = "avans-v4"` → `avans-v5`), чтобы у пользователей обновилось.
