Журнал выдач

Нет доступа к серверу данных

Сервер отклонил запросы приложения. Скорее всего, обновляется защита данных или ключи не совпадают. Что проверить:

  1. В Apps Script таблицы (Расширения → Apps Script) стоит код с авторизацией, а не старая версия
  2. В CONFIG.USERS в Apps Script есть пользователь с вашим кодом доступа
  3. Развертывание обновлено: «Развернуть» → «Управление развертываниями» → карандаш → «Новая версия»
  4. Доступ к таблице — «Ограниченный»: скрипт работает от имени владельца и продолжит писать

Данные в любом случае не теряются: пока нет связи, приложение показывает последнюю сохранённую копию на устройстве.
